<h3 align="center">Shellfin</h3>
<p align="center">Open-source, cross-platform SSH client — terminals, an SFTP file tree and a built-in editor.</p>

---

**Shellfin** is a desktop SSH client for Windows, Linux and macOS, built with Rust and Tauri.

- Multiple connections in tabs, several terminals per connection
- Remote file tree over SFTP with a simple, conflict-safe editor
- Reads your `~/.ssh/config` and `known_hosts`; strict host-key verification
- Passwords live only in your OS keychain
- Dark and light themes, English and Ukrainian, automatic signed updates
